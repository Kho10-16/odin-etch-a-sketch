# Etch-a-Sketch

A browser-based sketchpad built for The Odin Project Foundations course.

## Features
- Grid of squares generated with JavaScript
- Hover over squares to draw
- Button to create a new grid (1–100 squares per side) in the same total space

## Skills practiced
- DOM manipulation (querySelector, createElement, appendChild)
- Event listeners (mouseenter, click)
- Flexbox layout and box-sizing
- Input validation with prompt
